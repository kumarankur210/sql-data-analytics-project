# SQL Data Analytics Project

A SQL-based data analytics project focused on transforming sales data into meaningful business insights using **Microsoft SQL Server**.

This project demonstrates how SQL can be used to explore customer behavior, product performance, sales trends, and other business metrics through structured analytical queries.

---

## 📌 Project Overview

The goal of this project is to analyze sales data and answer important business questions using SQL.

The project covers the complete analytics process:

**Raw Data → Data Exploration → Data Analysis → Business Insights**

The analysis focuses on three major areas:

- 👥 Customer Analysis
- 📦 Product Analysis
- 💰 Sales Analysis

The project is designed to demonstrate practical SQL skills that are commonly used in data analyst and business intelligence roles.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Explore and understand the available sales data
- Analyze customer purchasing behavior
- Identify top-performing products
- Analyze sales performance over time
- Calculate important business KPIs
- Segment customers based on purchasing behavior
- Identify high-value customers
- Understand product performance
- Generate actionable business insights using SQL
